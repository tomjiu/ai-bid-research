## 3. 运行期新发现（并入问题清单）

1. **MDCORE_REV 常量错报**：BASELINE env.mdcore_rev = `aa0c859d…`，实际钉住 rev = `f4328ebf…`（bid-engine/Cargo.toml）——常量未随 rev bump 更新（Agent B 静态发现的运行时坐实）。P3 → 诊断面误导（凡消费该常量的对账脚本都会对错版本）。
2. **harness 复跑覆写仓内基线**：BASELINE.json 无条件写回仓内路径（--out 只管 results/）——评测产物被本地复跑改写（与 §测试副作用同族）。
3. **pdfium ENV_MISSING → PDF 引擎通道整体回退旧路径**：本轮全部 PDF 走 poppler 旧路径；pdfium 通道（B5 引擎路径）在无动态库环境零覆盖——与 T18a（引擎路径评测断裂）共同构成「引擎路径未被验证」的证据链。
4. A-02 扫描件 OCR 在缺 chi_sim 时**响亮失败**（不伪装）✅——但意味着扫描件路径在本轮零验证（NEEDS_ENV：补 chi_sim 复跑）。
