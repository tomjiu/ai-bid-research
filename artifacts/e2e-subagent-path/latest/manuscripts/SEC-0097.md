# 资格条件（第6块）

## 一、对资格审查方式的总体响应

招标文件第3.2.1条（资格审查方式）明确规定："本项目采用资格后审。投标人资格条件按第一章招标公告「二、投标人资格要求」的规定执行。"（[REQ-0019]）对该条款所确立的审查方式与资格条件适用规则，我方已逐字逐句研读并完全理解，现作出如下总体响应。

（一）我方完全知悉并无条件接受本项目采用资格后审的审查方式。资格后审意味着招标人不在投标前单独设置资格预审环节，而是在开标后由评标委员会依据招标文件载明的统一标准和方法，对投标人是否满足第一章招标公告「二、投标人资格要求」的各项规定逐项进行审查。与资格预审相比，资格后审对投标人提出了更高的自我约束要求：其一，全部资格证明材料必须随投标文件一次性、完整、规范地提交，审查中发现的资格瑕疵原则上不再给予补正机会；其二，资格文件的编排质量直接影响评标委员会的核验效率，任何信息缺失、索引不清都可能被从严把握。我方对此有充分认识，并已按照"逐条对应、要素齐全、随时可验"的原则完成本章及资格文件分册的编制。

（二）在投标准备阶段，我方组织资质管理、法务合规、人力资源、财务管理四条业务线，对第一章招标公告「二、投标人资格要求」的全部条款进行联合自查。自查采取"编制—审核—审定"三级复核程序，逐条比对证书有效期、人员社保缴纳状态、业绩合同与验收文件的对应关系等易错要素。自查结论为：我方完全满足该部分所列的全部资格条件，不存在任何一项不满足、部分满足或附条件满足的情形，亦不存在招标文件及现行法律法规规定的禁止投标、限制投标情形。

（三）为便于评标委员会在资格后审环节快速定位与核验，本章第二节采用"资格要求事项—我方响应情况—对应证明文件"的逐项对应结构组织内容，并在第二节末尾附资格条件符合性自查汇总表；凡我方主张具备的资质、业绩、人员、财务与信誉事项，均随附证明文件复印件或明确注明其在投标文件中的具体位置，做到言之有据、查之有物。

（四）我方郑重承诺：若资格后审中查明我方提交的任何资格证明材料存在伪造、变造、失效、涂改或与事实不符的情形，或查明我方实际状况不满足招标公告「二、投标人资格要求」的任何一款规定，我方无条件接受由此产生的全部后果，包括但不限于被认定为无效投标、取消中标候选人或中标人资格、不予退还投标保证金，并依法承担相应的行政责任与民事赔偿责任。

（五）特别说明：我方持有有效的电子与智能化工程专业承包二级资质证书（[EV-0128]），适用范围为电子与智能化工程，与本项目招标工程内容完全对口，构成本次投标的核心资质支撑。围绕该资质所对应的承包工程范围、类似工程业绩、专业技术人员与施工装备，我方在本章第二节逐项展开说明，并在第五节将资格能力进一步落实为进度、人员、设备三个维度的可核验量化承诺。
