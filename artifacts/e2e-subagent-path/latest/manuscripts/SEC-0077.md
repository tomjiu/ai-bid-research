# 否决项（第38块）

## 一、否决项响应总体说明

否决项是招标文件中必须逐条响应并逐条满足的条款，任何一条出现遗漏、偏差或虚假响应，都将直接导致投标被认定为未响应甚至无效，其后果是丧失投标资格。我方在投标文件编制启动阶段，即依据 synth-tender 招标文件，组织投标文件编制负责人、法务审核人员、文书专员等，对全部否决项及其响应要求逐句进行了闭环拆解，并建立了“拆解到位、响应到位、核验到位、承诺到位”的响应管控机制：所有否决项均纳入《否决项响应对照清单》实行台账管理，逐项明确责任人、完成节点与核验方式；投标文件须经编制组自检、法务复核、投标领导小组终审三级审核通过后方可封标递交；凡涉及否决项的文件原件、复印件一致性均在递交前逐项核对。

针对本章所涉授权委托书否决项要求[REQ-0068]，我方总体响应立场为：完全接受、完全响应、无保留、无偏差。我方本次投标所提交的授权委托书，将由我方法定代表人本人签发并加盖投标人公章；其有效期将完整覆盖自投标截止、开标、评标、澄清答疑直至中标通知与合同签订的全过程，具体量化标准以本章响应细则为准。支撑我方作出上述响应的主体资格依据为[EV-0128]：我方取得的电子与智能化工程专业承包二级资质证书（证据路径：synth·subagent-path），适用范围为电子与智能化工程；该资质证书所载企业名称、证书编号等登记信息，将与授权委托书、投标函等投标文件中的投标人主体信息严格一致，确保投标文件主体要素统一、真实、可查，为评标委员会提供可资交叉核验的依据。

本章按如下顺序展开：首先对[REQ-0068]进行要素化拆解，明确其必须满足的构成要件；其次，就出具主体要素与有效期要素、授权委托书的格式与内容要素、常见错误规避、佐证材料与交叉核验、法律后果承诺逐项作出响应承诺；再次，就进度、人员、设备三个维度给出可核验的量化承诺；最后给出响应对照表及书面承诺。本章全部响应内容，均以我方在开标时提交的原始文件为准，原件随时可供招标人及评标委员会查验。

## 二、对[REQ-0068]的逐项响应

### （一）要求条款拆解

[REQ-0068]规定：“3 授权委托书 授权委托书须为法定代表人出具且在有效期内”。经认真拆解，该否决项包含两个必须同时满足的构成要件：

**其一，出具主体要件：授权委托书须为法定代表人出具。** 即该文书的委托人必须是经登记机关登记、并载于营业执照上的法定代表人本人，而非投标人的子公司、分公司、部门、项目部，亦非投标人的其他高管或员工。依据《中华人民共和国民法典》关于委托代理的有关规定，授权委托书属于单方民事法律行为，只有当委托人为法定代表人时，其代表投标人参与招标活动行使程序性与实体性权利的外部效果方可正当发生；若以他人名义出具，则代理关系自始存在瑕疵，受托人此后以投标人名义实施行为的效力将直接受到影响。

**其二，有效期要件：授权委托书须在有效期内。** 所谓在有效期内，是指授权委托书自投标递交、开标、评标、澄清答疑、中标通知接收等各个关键时间节点，直至授权事项办理完毕为止，均须保持有效状态（既未生效之前不算，失效之后亦不算）。该要件可进一步分解为三个审查维度：起点（文书的生效日）、终点（文书的失效日）、覆盖面（期限是否完整覆盖招标文件规定的投标有效期及合同签订期）。实务中常见风险，是出具方按惯例将有效期设置过短，导致文书在中标及签约之前即告届满，从而被认定不满足本否决项。

我方理解：上述两项要件缺任一项，即授权委托书系以他人名义出具、或授权未生效或已失效，均构成对本否决项的不响应，我方无条件接受由此被否决或废标的评定后果。正是基于其一票否决后果的直接性与严重性，我方将本条款列为投标文件质量管控清单中的红线条款，由公司法务层级实施审核把关，并在投标文件封标递交前由专人对本条再次复核确认，确保投标文件递交之时，授权委托书在“人对、期对”两个要件上不存在任何偏差。

### （二）出具主体要素的响应承诺

针对[REQ-0068]中“授权委托书须为法定代表人出具”，我方逐项响应承诺如下：

**第一，委托主体真实且唯一。** 本项目授权委托书由我方法定代表人本人签发，该法定代表人为经登记机关登记并载于营业执照上的法定代表人。授权委托书上的手写签名将由法定代表人本人当面签署，同时加盖投标人公章，不以私章、部门章、分支机构章、电子签名或他人签字替代；不存在层层授权、转委托的情形；若在招标期间因登记事项发生法定代表人变更，我方将在第一时间书面告知招标人，并按新登记信息重新出具授权委托书，确保授权关系连续有效。

**第二，主体要素一致。** 授权委托书中填写的投标人全称、统一社会信用代码、法定代表人姓名，与我方所持[EV-0128]（适用范围：电子与智能化工程）等资质证书及营业执照上的对应登记信息严格一致，确保文书主体真实有效、信息互证，便于评标委员会通过资质证书交叉核验投标人主体真实性与文书来源一致性。

**第三，受托人真实合法。** 受托人为与我方签订劳动合同、由我方缴纳社会保险的在职人员；其姓名、性别、职务、身份证件类型及号码、联系电话等均如实填写于文书，并附受托人有效身份证件复印件（开标时可出示原件备查）；受托人将持本人身份证原件与本授权委托书原件按时到达开标现场接受身份核验。受托人在我方的任职岗位及职责分工将如实说明，便于评标委员会通过社保缴纳记录核验其与我方劳动关系的真实性。

**第四，授权范围明确。** 文书将明确列举授权事项：代表我方参与本项目招标活动，包括递交投标文件、出席开标会议、答疑与确认、澄清与答复、原件查验，以及处理与本招标有关的其他事务；涉及中标后合同谈判与签订的事项，亦在文书内由法定代表人一并明确授权，并将授权范围与限制逐项写明，避免出现越权争议。

### （三）有效期要素的响应承诺

针对[REQ-0068]中“且在有效期内”，我方逐项响应承诺及量化标准如下：

**第一，生效起点明确。** 授权委托书将明确写明自出具之日（即法定代表人签字盖章之日）起生效，不附任何可能导致生效时间不确定的条件或期限，确保文书一经签署即行生效，并自投标截止之日起至授权事项办理完毕为止持续有效。

**第二，有效终点量化且充分。** 我方承诺：本授权委托书有效期自投标截止之日起按120个日历日设置；若招标文件另行规定的投标有效期长于120日，则授权委托书有效期自动顺延覆盖投标有效期加30个日历日，我方将在投标有效期届满前办妥顺延手续并书面告知招标人。该期限标准已完整覆盖开标、评标、澄清答疑、中标通知、合同签订的正常周期，并留有充分时间余量，确保在定标签约前的任一时间节点均不存在期限风险。

**第三，有效期动态监控。** 我方指定文书专员对文书实行台账管理，自出具之时即登记电子台账，并按节点对期限进行监控：有效期届满前60日第一次提醒、届满前30日第二次提醒、最迟于届满前15日启动顺延或重新出具程序，确保招标与定标期间授权委托书始终处于有效状态，绝不出现授权到期后无人跟进的情况。

**第四，失效后果明示。** 文书将明示：有效期届满后授权关系自动终止，受托人不得再以我方名义实施授权事项；未完成事项由法定代表人亲自办理或另行出具授权；如因客观原因需要变更或撤回授权，我方将第一时间书面告知招标人，不影响招标人既定日程与招标程序。

### （四）授权委托书的格式与内容要素

为一次性满足[REQ-0068]的形式审查要求，我方将严格按招标文件规定的格式文本出具授权委托书，内容要素包括：（1）文书名称：授权委托书；（2）委托人信息：我方全称、统一社会信用代码、住所地及法定代表人姓名；（3）受托人信息：姓名、性别、职务、身份证件类型及号码、联系电话；（4）授权声明：以文字表述我方法定代表人兹授权受托人代表我方参与本项目招标活动；（5）授权范围：逐项列明具体授权事项，涵盖递交投标文件、出席开标、答疑、澄清与答复、原件查验、合同签订等；（6）授权期限：起止日期以文字和数字同时表述，天数计算精确到日；（7）限制性声明：受托人无权转授权、无权转委托、无权超越授权范围，法定代表人保留监督与撤销授权的权利；（8）签章：法定代表人手写签名并加盖投标人公章，签章清晰、齐全、无错盖；（9）出具日期：以年月日格式写明；（10）附件：受托人身份证件复印件、社保缴纳证明、载有法定代表人登记信息的营业执照复印件。

以上要素将由我方法务审核人员对照《授权委托书要素核验单》逐项核验，核验记录随投标文件一并存档，随时可提供给招标人及评标委员会查验；如招标文件格式对文书要素另有规定的，我方按招标文件规定优先的原则一并满足，不作任何偏差或遗漏。

### （五）常见错误类型与我方规避措施

结合招标实践中授权委托书常见的否决情形，我方逐项梳理五类高频错误并制定对应规避措施：**一是主体错误**，即以分公司、子公司或部门负责人名义出具——规避措施：委托人栏一律由法务审核人员对照营业执照核验后填写，编制组不得自行填写或变更；**二是有效期不足**，即期限未覆盖投标有效期或签约期——规避措施：期限一律按投标截止日起120个日历日、招标文件另有规定则自动顺延的量化标准统一设定，并由专人复核天数；**三是签章不到位**，即缺手写签名、公章模糊或错盖——规避措施：签署后由印章保管人与文书专员共同当面核验签名真实性与印章清晰度，并扫描存档备查；**四是信息不一致**，即受托人姓名或证件号码与证件复印件、社保记录不符——规避措施：受托人信息一律由文书专员对照证件原件誊录，法务再行复核一遍；**五是附件遗漏**，即身份证件复印件、社保证明等缺项——规避措施：附件完整性纳入封标前最后一道检查，逐项打钩签认，缺项不得封标。上述五类措施已嵌入我方《投标文件质量管控清单》，将在本次投标编制过程中逐项落实、台账管理。
