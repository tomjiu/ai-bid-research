## 二、对 [REQ-0054] 否决情形的理解

### 2.1 条款定位与规制目的

[REQ-0054] 位于否决项条款体系之中，属于规制串通投标行为的兜底性情形。其所否定的行为在主观上须具有「谋取中标或者排斥特定投标人」的共同故意，在客观上须表现为投标人之间实施的「联合行动」，二者缺一不可。设置该条款的目的，在于维护招标投标活动的竞争充分性与结果公正性：一旦允许投标人通过联合行动操纵竞争格局，报价的真实性、方案的比选价值乃至整个评标秩序都将失去基础。本投标人完全认同该条款的规制目的，并以之作为本次投标行为合规性的最高准绳之一。

从规范依据看，投标人之间相互串通投标报价、排挤其他投标人的公平竞争、损害招标人或者其他投标人合法权益的行为，为招标投标法律制度所明令禁止；情节严重的，还可能构成犯罪。招标文件将 [REQ-0054] 列为否决项，正是将上述禁止性规范转化为资格审查与评标环节的直接否决条件。本投标人对该条款的严肃性有充分认知，并以下述自查与承诺予以完整响应。

### 2.2 「其他联合行动」的典型形态

结合招标投标法律、行政法规、部门规章及评标实践，「其他联合行动」通常表现为以下五类典型形态：

（1）报价协同类：投标人之间就投标报价的区间、梯度、让利幅度或者取整方式进行约定或默契配合，使各投标人报价呈现人为设计的排布结构；

（2）编制协同类：不同投标人的投标文件由同一主体或者相互通气的若干主体编制、校核或者修改，导致文件的格式特征、错误特征、字体版式、制作机器码等异常一致；

（3）信息交换类：投标人之间交换与投标有关的成本数据、报价意向、竞争策略或者从招标人处非法获取的标底信息，使各自的投标行为丧失独立性；

（4）分工围标类：投标人之间约定由其中一方真实投标、其余各方陪标凑数，或者约定轮流中标、对落标方给予补偿、对中标方进行利益输送；

（5）排斥协同类：投标人之间联合抬价或者压价，或者通过威胁、利诱、排他性约定等手段，诱使、迫使特定投标人退出竞争或者落标，以排斥特定投标人。

### 2.3 适用要件

对照条款文义，适用 [REQ-0054] 予以否决，须同时满足三项要件：其一，主体为两家或者两家以上投标人；其二，各方之间存在共同的意思联络，即「联合」的合意；其三，联合的目的指向谋取中标或者排斥特定投标人，且已付诸行动。本投标人在本项目中的全部行为均不满足上述任何一项要件：本投标人为独立民事主体，未与任何其他投标人形成任何意思联络，更未实施任何联合性质的行动。以下第三节将以逐项对照方式予以证明。
