# 否决项（第24块）

## 一、条款接收确认与总体响应立场

针对招标文件 [REQ-0047] 所载 3.7.3 条之否决规则——"评标委员会在评标过程中发现投标人有下列情形之一的，视为投标人相互串通投标，其投标将被否决"——我方已组织投标工作组全体成员逐字研读、逐条领会，并据此完成了覆盖投标准备至投标递交全过程的合规自查。我方在此郑重声明：**本次投标系我方基于自身经营状况、技术能力与独立采集的市场价格信息自主作出的商业决策，与任何其他投标人之间不存在意思联络、报价协商、利益安排或其他任何形式的协同行为，不存在 [REQ-0047] 所指"视为投标人相互串通投标"的任何一种情形。**

我方充分理解，该条款属于刚性否决项：评标委员会一经查实投标人存在串通投标情形，即可直接否决其投标，且不适用澄清、补正等补救程序。正因如此，我方不回避、不淡化该条款的适用，而是主动将其作为本次投标合规管理的最高优先级控制目标，在文件编制、保证金缴纳、印制封装、现场递交等全部环节设置可核验的留痕机制与物理隔离措施，确保评标委员会在核查时能够随时调取原始证据，验证我方投标行为的独立性、真实性与合法性。

我方同时确认：我方以自身名义投标、以自身资质响应、以自身账户缴纳投标保证金、以自身全职人员组建项目管理机构，全过程不存在借用资质、挂靠经营、借用他人名义或与他人共用资源投标的情形。我方持有 [EV-0128] 电子与智能化工程专业承包二级资质证书（synth·subagent-path），适用范围为电子与智能化工程，系我方依法定程序自行考核取得的独立资质，证书信息可通过全国建筑市场监管公共服务平台等官方渠道在线核验。以自有独立资质参与本次投标，正是我方不依赖、不借用任何第三方资源的直接证明。

## 二、对 [REQ-0047] 各类否决情形的逐项自查与响应

依据 [REQ-0047]，评标委员会在评标过程中发现投标人存在法定串通投标情形之一的，视为投标人相互串通投标，其投标将被否决。我方对照该条款所指向的"视为相互串通投标"各类典型情形——包括但不限于：不同投标人的投标文件由同一单位或者个人编制；不同投标人委托同一单位或者个人办理投标事宜；不同投标人的投标文件载明的项目管理成员为同一人；不同投标人的投标文件异常一致或者投标报价呈规律性差异；不同投标人的投标文件相互混装；不同投标人的投标保证金从同一单位或者个人的账户转出——逐项开展了自查。逐项自查结论与可核验佐证如下。

### 2.1 关于"投标文件由同一单位或者个人编制"的自查与响应

我方投标文件由我方自有投标团队在我方自有办公场所、使用我方登记在册的自有设备独立编制完成。本次投标编制组共配置人员9名：商务组3人负责资格文件与商务条款响应，技术组4人负责施工组织设计与技术方案编制，报价组2人负责工程量清单计价与成本测算。全部人员均为我方在册全职员工，其劳动合同与社会保险缴纳记录可提交评标委员会核验。编制过程中，我方未委托任何招标代理、造价咨询或其他第三方机构、个人代为编制，未购买或使用任何来源不明的投标文件模板，未与任何其他投标人共享编制成果、文档模板或数据底稿。

为使"独立编制"具备可核验性，我方在编制期间实行版本留痕管理：投标文件按"日期＋版本号＋编制人"规则命名，自初稿至终稿累计形成版本记录21个，每一版本的修改人、修改时间与修改内容摘要均在《投标文件编制过程记录表》中登记；编制所用计算机为物理断网的专用设备，文件不出现在任何共享网盘、即时通讯群组或其他公共传输渠道。评标委员会如需核验，我方可在接到通知后24小时内提交全部版本记录、过程稿及《投标文件编制过程记录表》原件。

### 2.2 关于"委托同一单位或者个人办理投标事宜"的自查与响应

本次投标的全部事宜——包括招标文件领购、澄清答疑、现场踏勘、投标文件编制、保证金缴纳、文件封装与递交——均由我方在职员工以我方名义办理，未与其他投标人共用任何代理机构、代理人或办事人员。我方经办授权代表系我方正式员工，持我方法定代表人签署的授权委托书，其身份信息、劳动合同与社会保险缴纳记录均已按规定编入投标文件，可供评标委员会逐项核对。我方承诺：在投标有效期内，我方办理本招标项目相关事宜的人员名单保持唯一且可随时核验；如评标委员会发现我方经办人员同时出现于其他投标人的办理链条之中，我方无条件接受按 [REQ-0047] 作出否决处理。

### 2.3 关于"项目管理成员为同一人"的自查与响应

我方投标文件载明的项目管理机构成员共7名：项目负责人（项目经理）1名、技术负责人1名、施工员1名、质量员1名、安全员1名、材料员1名、资料员1名，全部为我方全职员工，与我方签订劳动合同并由我方连续缴纳社会保险。上述成员均未在任何其他投标人处任职、投保或登记为项目管理成员；涉及注册执业资格的成员，其执业资格均注册于我方名下，注册单位与投标单位一致。我方可在评标委员会要求时提交上述成员的劳动合同复印件、投标截止日前连续6个月的社会保险缴纳明细及注册执业资格证书复印件，供逐人核对。若评标委员会查实我方项目管理成员与任何其他投标人载明的成员存在重合，我方自愿接受投标被否决并承担相应法律后果。

### 2.4 关于"投标文件异常一致或投标报价呈规律性差异"的自查与响应

我方投标报价由报价组依据企业自身定额、自有机械台班成本、已完类似工程成本数据及独立开展的市场询价结果测算形成：投标截止日前12日内完成不少于3轮的人工、材料、机械分项询价，询价对象不少于9家供应商，询价书面记录（报价单、询价登记表）全部留存备查。我方报价的让利幅度来源于对我方管理费率的独立测算，并非整数点位或固定比例的机械让利；投标总价与分部分项综合单价均由成本明细逐项累加生成，与其他投标人报价构成等差、等比或其他规律性对应关系在形成机制上即被排除。技术标方面，我方施工组织设计结合现场踏勘所得具体条件与我方自有设备、自有队伍情况编制，章节结构、图表样式与文字表述均由我方编制人员独立撰写，未套用任何共享范本。

需要特别说明的是，我方报价的组价路径具有个体唯一性：分部分项综合单价按"人工费＋材料费＋机械费＋管理费＋利润＋风险费用"逐项组价，其中人工工日单价取自我方与作业班组签订的劳务协议价，材料单价取自询价记录的加权结果，机械台班单价取自我方自有机械的折旧与运维台账，管理费率与利润率由我方近三年已完工程的成本核算数据推导得出。上述四类基础数据均唯一来源于我方自身经营记录，组价结果因而带有我方个体成本特征，客观上不与其他投标人呈现规律性差异。

我方同意并主动配合评标委员会对投标文件进行文本相似度比对与报价规律性分析：比对所需电子版文件随纸质文件一并密封提交；如需成本测算底稿与询价记录，我方在接到通知后24小时内提供。比对或分析结果若显示异常，我方接受评标委员会依据 [REQ-0047] 作出的认定。

### 2.5 关于"投标文件相互混装"的自查与响应

我方投标文件的全部打印、装订、封装作业均在我方自有办公区内的独立作业间完成，作业期间实行双人复核制：装订前由2名复核人员对照目录逐册清点页码与册数；封装后由2名复核人员共同检查密封袋外观、密封条完整性与标识信息，确认每一密封袋内仅装有我方单一投标人的文件。密封袋封面按规定载明项目名称、标段号、投标人名称、正副本标识及"开标前不得启封"字样，密封处加盖我方单位公章。装订封装期间，我方办公区未接待任何其他投标人的经办人员，亦未接收任何来源不明的密封文件，从物理上排除了混装、错装与夹带的可能。

### 2.6 关于"投标保证金从同一单位或者个人的账户转出"的自查与响应

我方投标保证金已由我方基本存款账户以银行转账方式一次性足额缴纳至招标文件载明的收款账户，银行回单已按招标文件要求编入投标文件；回单显示的付款账户户名、账号、开户行与我方营业执照登记信息完全一致。我方承诺：该笔保证金资金来源为我方自有资金，不来自任何其他投标人、任何与其他投标人存在关联的单位或个人，亦不存在他人代缴、代垫的情形。评标委员会可调取银行流水核验资金划出账户的唯一性与独立性，我方同时可提交基本存款账户信息证明文件备查。若查实我方保证金与其他投标人保证金出自同一账户，我方无条件接受按 [REQ-0047] 否决投标并按招标文件约定处理保证金。

### 2.7 关于其他协同投标情形的自查与响应

除上述情形外，我方就其他常见协同投标情形一并自查并声明如下。其一，我方未与其他任何投标人约定抬高或者压低投标报价，未约定在本次招标项目中分别以高、中、低价位报价，未约定部分投标人放弃投标或者放弃中标，未约定由某一投标人统一编制投标文件后分发使用。其二，我方与本次招标的其他投标人之间不存在下列任何一种关联：相互直接或间接持股，法定代表人为同一人，董事、监事、高级管理人员相互交叉任职，或直接、间接同为第三方控制；我方虽为个别行业协会会员单位，但从未按任何协会、商会或其他组织的统一要求或安排参与协同投标，本次投标的报价与方案均由我方独立决策。其三，我方不存在向招标人、招标代理机构或者评标委员会成员行贿或谋取其他不正当利益的行为，亦未以任何方式打探标底、评标委员会成员名单等依法应当保密的信息。以上声明如有不实，我方自愿承担由此产生的全部法律责任。

## 三、资格证据与 [REQ-0047] 响应的对应关系

就 [REQ-0047] 的否决规则而言，投标人资格的独立性与真实性是排除串通投标嫌疑的基础性证据。我方为此提交的资格证据材料为 [EV-0128]——电子与智能化工程专业承包二级资质证书（synth·subagent-path），适用范围为电子与智能化工程，与本项目招标范围直接对应。该资质证书系我方作为独立法人依申请、依考核程序自行取得，证书载明的单位名称、统一社会信用代码与本次投标文件、投标保证金付款账户、授权委托书及公章印鉴完全一致，形成"资质主体—投标主体—缴费主体—签章主体"四位一体的对应闭环。

资格独立性对 [REQ-0047] 的证明意义体现在三个层面。第一，我方以 [EV-0128] 自有资质投标，不存在借用、租用、挂靠他人资质的情形，而借用资质往往是多个投标人受同一实际控制人操纵、进而被认定为串通投标的高发路径，我方从资格源头切断了该路径。第二，[EV-0128] 的取得以我方独立的技术负责人、注册人员与净资产为条件，上述人员与资产均唯一归属我方，不存在与其他投标人共用人员或资产的情形。第三，该资质项下我方可独立承接电子与智能化工程施工，无需与任何第三方形成"一套班子、多块牌子"的结构，本次投标的全部能力要素均由我方自持。

此外，为便于评标委员会快速核验，我方在投标文件资格部分将 [EV-0128] 的证书编号、发证机关、发证日期与有效期逐项列明，并与营业执照等其他主体资格文件共同编入"主体一致性对照表"，对资质主体、投标签章主体、保证金付款主体、授权代表劳动关系主体、项目负责人注册单位五项要素逐项标注；任一项不一致即视为核验失败。我方近三年类似业绩合同与竣工验收证明所载承包人主体亦均与我方营业执照主体一致，可进一步佐证我方经营活动的独立性与连续性。[EV-0128] 的持证信息可通过全国建筑市场监管公共服务平台及省级住建主管部门官方渠道在线查询，我方承诺投标文件所载资质信息与官方登记信息完全一致；如核验发现任何不一致，我方接受按招标文件否决项条款处理。
