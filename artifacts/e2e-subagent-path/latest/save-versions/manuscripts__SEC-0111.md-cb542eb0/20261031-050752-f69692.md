# 评分项（第6块）

## 一、对本评分规则的逐句理解与总体响应

[REQ-0080] 规定：「4.7 评标委员会按照得分由高到低排序推荐中标候选人，并出具评标报告；得分相同的，投标报价低者优先。」我方已逐字研读、准确理解并完全接受该条款的全部效力。作为应答方，我方在本章节对该条款进行逐句拆解与对应响应：该条款由三个要件构成——其一为排序规则，即评标委员会以各投标人综合得分为唯一尺度进行降序排列，并按该排序推荐中标候选人；其二为程序要件，即评标委员会须出具评标报告，对评标过程、分项得分与推荐结论予以固化；其三为同分处理规则，即当两个及以上投标人综合得分完全相同时，投标报价较低者排序在前、优先推荐。围绕上述三个要件，我方分别在本章节第一节至第三节作出理解与响应，并按照招标文件对可核验量化承诺的要求，在第四至第六节给出进度、人员、设备三个方面的量化承诺，全部承诺均落到具体数字、时间节点与考核方式，不含空话与不可验证的表述。

### （一）对「按照得分由高到低排序推荐中标候选人」的理解与响应

我方理解：综合得分是本次评标排序的唯一尺度，评标委员会将依据各投标人获得的分项得分加总形成的综合得分进行降序排列，并按排序结果推荐中标候选人。这一排序原则对投标文件提出了三点刚性要求：第一，无漏项，招标文件中每一项可评分的要求都必须在投标文件中找到对应响应，任何缺项都意味着该分项直接失分；第二，可核验，响应内容必须具体到可检查的程度，评标专家依据响应内容即可独立作出满足与否的判断，而不需要投标人另行解释；第三，一致性，各章节之间的数据与承诺必须口径统一，避免出现前后矛盾导致评标委员会无法采信的情况。

基于上述理解，我方对全本投标文件执行「逐条对应、逐条响应、逐条可查」的编制原则，具体措施包括：第一，建立条款对照索引，将招标文件全部商务与技术要求逐条编号并与投标文件响应章节建立对应关系，供评标专家快速定位；第二，承诺清单化，所有实质性承诺均以数字、时间节点、验收标准三要素表述，杜绝「完全满足」「性能优异」等无法评分验证的空泛表述；第三，如出现负偏离事项，我方在投标文件中明确列示并附具补偿措施，不采用回避或模糊表述的方式规避扣分；第四，全本数据一致性自查，投标文件定稿前完成三轮交叉校核，确保人员、设备、进度、报价四类数据在商务卷、技术卷、报价卷中完全一致。

### （二）对「并出具评标报告」的理解与响应

我方理解：出具评标报告是评标委员会的法定职责与必经程序，评标报告将记录各投标人的分项得分、综合得分、排序结果与推荐结论，并可能载明评标过程中发现的重大问题、澄清事项的往来与处理情况。这一程序要件对投标人形成了直接约束：投标文件中的全部陈述都必须经得起评标报告的固化与后续查验，任何不实陈述、前后矛盾或无法自圆其说的内容，一旦进入澄清或复核环节即会暴露，并将直接影响评标委员会对我方投标的可信度评价。

据此，我方作出如下响应与承诺：第一，真实性承诺，本投标文件全部内容真实、准确、完整，不存在虚假陈述、伪造材料或误导性表述，我方对全部内容的真实性承担法律责任；第二，一致性承诺，投标文件各章节中的人员数量、设备清单、进度节点、报价金额等关键数据口径统一，评标委员会在任何章节查到的同一事项数据完全一致；第三，澄清配合承诺，评标期间我方保持投标文件所载联系人24小时通讯畅通，收到评标委员会澄清通知后24小时内作出书面答复，答复内容严格限于投标文件已有范围，不改变投标文件的实质性内容；第四，程序接受承诺，我方接受评标委员会出具评标报告并按 [REQ-0080] 规则推荐中标候选人的程序与结果，配合完成后续的公示、异议答复与签约工作。

### （三）对「得分相同的，投标报价低者优先」的理解与响应

我方理解：本款确立了同分情形下的优先次序规则，当两个及以上投标人的综合得分完全相同时，投标报价较低者排序在前、优先推荐为中标候选人。该规则的实际含义是：在技术方案与商务响应难分高下、综合得分打平的极端竞争情形下，价格将成为决定推荐位次的最终变量。这对投标人的报价策略提出了明确要求——报价必须同时满足两个条件：一是具备竞争力，确保在可能的同分比较中处于价格优势位置；二是理性可持续，不得低于成本报价，确保中标后能够按承诺质量履约。

据此，我方对报价进行了审慎测算与竞争性定位：以完整的成本分解结构为基础，覆盖人工、材料、设备、分包、管理、税费与风险准备金等全部成本要素，在确保不低于成本、可持续履约的前提下，通过管理优化、供应链集中采购与内部让利形成具有竞争力的最终报价。具体的报价构成公开、优惠让利与价格保持承诺，详见本章节第三节。我方同时声明：我方充分知悉并接受 [REQ-0080] 确立的同分低价优先规则，不以任何方式试图规避或影响该规则的适用。

## 二、面向得分排序的投标竞争力构成设计

依据 [REQ-0080] 确立的「得分由高到低」总排序原则，综合得分中的每一个分项都直接影响排序位次。我方据此从技术响应、商务响应、价格竞争三个得分维度，辅以履约保障维度，对投标文件进行系统设计，确保各分项得分最大化、无遗漏、可核验。

（一）技术响应维度。我方对招标文件全部技术要求逐项列表响应，每项均标注「满足」或「优于」：对「满足」项，给出与要求指标的逐一对照；对「优于」项，同时给出量化差值与验证方法。凡涉及性能、容量、精度、时限的技术指标，均以具体数值应答，不使用「先进」「行业领先」等无法评分验证的形容词。对招标文件允许偏离的事项，我方全部作出正偏离或零偏离响应，本投标文件不含未说明的技术负偏离。

（二）商务响应维度。资格条件与类似业绩是评分体系中的常见得分项，依据 [REQ-0080] 确立的得分排序原则，此类材料的完整性与可核验性直接决定分项得分。我方对资格条件、类似业绩、财务状况、信用记录等商务要素逐项对照响应，材料按「清单化、页码化、原件备查」三原则组织：每一项要求对应一份材料清单，清单注明材料名称、份数、所在页码与对应的招标条款号，评标专家按清单即可完成核验；全部证书、证明文件均在有效期内，复印件与原件一致并加盖公章，原件在评标需要时随时可查；类似业绩按合同名称、合同金额、履行时间、验收结论、证明文件五要素列表呈现，逐项可查证。

（三）价格竞争维度。考虑到 [REQ-0080] 规定同分时低价优先，价格竞争力具有双重价值：既在价格分项本身得分，又在同分破局时决定位次。我方的价格策略是「成本测算扎实、竞争定位明确、承诺锁定优势」三位一体：以成本分解结构确保报价理性，以对标分析确保报价竞争性，以降价承诺与价格保持承诺锁定同分情形下的优先地位，具体承诺见第三节。

（四）履约保障维度。上述三个维度解决的是「得分」，履约保障维度解决的是「得分后的兑现」，二者共同构成评标委员会评价投标综合质量的完整视图。我方在投标文件中同步提交了质量保障、安全生产与违约责任承诺：质量目标为一次验收合格率不低于98%，终验一次通过；安全生产目标为零责任事故；任一量化承诺未兑现的，接受合同约定的违约金与采购人的考核处理。上述内容使本投标在 [REQ-0080] 排序规则下的竞争力具备完整的履约支撑。

（一）报价构成的完整性与审慎性。我方报价以完整的成本分解结构为基础，逐项覆盖人工费、材料费、设备使用费、分包费用、运输与安装费用、检测验收费用、管理费、税费与风险准备金九类成本要素，不漏项、不重复。在测算方法上，人工费按岗位工日单价乘以工日数量计算，材料费按市场询价三家以上供应商的加权报价计算，管理费按直接费用的比例上限控制，风险准备金按可识别风险清单逐项评估。上述测算过程与结果在投标文件报价卷中完整呈现，可供评标委员会核验，确保报价既具竞争力，又高于成本、可持续履约。

（二）价格竞争力的量化锁定。为确保在 [REQ-0080] 规定的同分低价优先情形下处于有利位置，我方作出如下可核验承诺：第一，让利锁定承诺，本次投标报价已包含合同期内全部优惠让利，合同履行期间不再以材料涨价、人工上涨等任何理由要求上调合同价格；第二，价格保持承诺，自投标截止之日起至合同签订之日，我方报价保持不变，不撤回、不修改；第三，算术修正接受承诺，如评标委员会依据评标规则对报价进行算术性修正，我方无条件接受修正结果，并按修正后的价格签订合同与结算；第四，支付条件响应承诺，我方完全接受招标文件规定的付款比例与付款节点，不附加任何变更付款条件的商务条款。
