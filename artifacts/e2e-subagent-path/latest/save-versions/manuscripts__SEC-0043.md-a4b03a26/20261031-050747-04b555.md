[REQ-0015] 所载否决情形原文为：「10 否决情形提示 未按本表第 9 项规定格式填写技术偏离表的，其投标作否决投标处理」。

我方高度认同招标文件设置该项否决情形的合理性与必要性。统一、规范的技术偏离表格式，是评标委员会对各投标人技术响应程度进行高效比对、准确评价、无歧义裁量的基础前提，是维护评标活动公平、公正与规范的重要制度安排，也是对全体投标人一视同仁的形式公平保障。我方完全接受该条款的全部要求，并以最严格的标准执行。
