## 二、对 [REQ-0010] 的逐条响应

### （一）条款理解与响应口径

[REQ-0010] 要求：“投标人参加政府采购活动前三年内，在经营活动中没有重大违法记录，并提供书面声明。”我公司对该条款的理解与响应口径如下：

第一，法律依据。该条款源于《中华人民共和国政府采购法》第二十二条第一款第（五）项，即供应商参加政府采购活动应当具备“参加政府采购活动前三年内，在经营活动中没有重大违法记录”的条件；招标文件1.4.7条将这一法定资格条件落实为“提供书面声明”的形式要求，我公司按该形式要求出具声明并随投标文件递交。

第二，“重大违法记录”的含义。按照《中华人民共和国政府采购法实施条例》第十九条的规定，重大违法记录是指供应商因违法经营受到刑事处罚或者责令停产停业、吊销许可证或者执照、较大数额罚款等行政处罚。其中“较大数额罚款”的认定标准，按照国务院有关部门和省级人民政府关于行政处罚听证的标准执行；为确保从严响应，我公司的自查口径不设罚款金额门槛，直接覆盖自查期间内的全部行政处罚记录。

第三，时间范围。自本项目投标截止之日起前溯三年（含起止当日），期间连续计算，不中断、不留空档。凡行政处罚决定的作出时间或者其载明的违法行为发生时间任一落入该期间的，均计入自查范围，不作有利于我公司的限缩解释。

第四，主体范围。以本投标文件项下的投标人我公司为自查主体，并同步覆盖该期间内我公司设立并存续的分公司；分公司在期间内的行政处罚记录，视同投标人自身的记录从严认定。

第五，应答形式。按招标文件要求出具书面声明，加盖我公司单位公章，由法定代表人或其正式书面授权的代表签字，随本投标文件一并递交，并按招标文件规定的正副本份数对应提供。

第六，条款定位。本条款属于资格性响应条款，其证明形式为书面声明，响应的核心在于声明的真实性、口径的从严性与结果的可核验性。为此，本章第二节（二）给出声明正式文本，第二节（三）至（六）给出支撑该声明的自查安排与边界说明，第三、四节分别给出持续合规承诺与量化保障安排。

第七，证明责任。开标后评标期间，采购人或者评标委员会要求就本声明进一步举证的，我公司在收到要求之日起2个工作日内提交自查留痕材料，不以任何理由拒绝提供官方公开渠道可以查询的信息。

### （三）自查流程、范围与核查渠道

为确保声明内容可核验、可追溯，我公司按照“查询—留痕—复核—审定—归档”五个步骤组织自查：查询步骤由合规专员按渠道清单逐项执行；留痕步骤同步留存载明查询日期与查询结果的页面记录；复核步骤由另一名合规专员与法务审核岗双人交叉复核；审定步骤由响应小组组长对自查结果与声明文本的一致性签字确认；归档步骤由文档管理岗统一编目存档。自查的范围与口径如下：

1. 时间范围。以本项目投标截止日为基准日前溯三年，按月连续覆盖，不遗漏、不留空档；为便于核验，按前溯顺序将三年期间划分为三个年度区间，逐区间核查并分别形成记录。
2. 主体范围。覆盖投标人本身及期间内存续的分公司，统一以“主体名称＋统一社会信用代码”双要素精确检索，避免同名主体误查、漏查。
3. 事项范围。包括四类从严认定事项（因违法经营受到刑事处罚、责令停产停业、吊销许可证或者执照、较大数额罚款）与名单类核查事项（失信被执行人、重大税收违法案件当事人、政府采购严重违法失信行为记录、经营异常名录、市场监督管理严重违法失信名单），并扩展至全部行政处罚记录。
4. 核查渠道。全部通过政府官方公开渠道进行，包括：国家企业信用信息公示系统，用于查询行政处罚信息、经营异常名录与严重违法失信名单；“信用中国”网站，用于查询失信被执行人、重大税收违法案件当事人名单与行政处罚记录；中国政府采购网，用于查询政府采购严重违法失信行为记录名单；中国裁判文书网，用于查询刑事裁判文书。
5. 记录留存。对每一渠道的每一次查询均留存完整页面记录，由查询人与复核人共同签字确认，与声明一并归档，留存期限不少于五年，供采购人、采购代理机构及监督管理部门随时调取核验。
6. 渠道更新跟踪。官方渠道功能或者数据发生调整的，由合规专员在2个工作日内确认替代查询路径并书面记录说明，确保自查口径不因渠道变化而弱化。

### （四）自查结果

按照上述流程、范围、口径与渠道，三个年度区间逐段核查、各类事项逐项核对，结果如下：

1. 刑事处罚方面：经查询中国裁判文书网、国家企业信用信息公示系统，自查期间内我公司及所涉分公司无因违法经营受到刑事处罚的记录；
2. 责令停产停业方面：经查询国家企业信用信息公示系统、“信用中国”网站，自查期间内我公司无被行政机关责令停产停业的记录，生产经营活动持续正常；
3. 吊销许可证或者执照方面：经查询国家企业信用信息公示系统，自查期间内我公司无被吊销许可证或者执照的记录，现行许可证照合法有效；
4. 较大数额罚款方面：自查期间内我公司无较大数额罚款记录；从严扩展自查的结果为无任何行政处罚记录；
5. 名单类核查方面：自查期间内我公司未列入失信被执行人名单、重大税收违法案件当事人名单、政府采购严重违法失信行为记录名单、经营异常名录及市场监督管理严重违法失信名单。

上述自查结果与本章第二节（二）声明文本的各项表述完全一致；三个年度区间的核查记录相互衔接、连续完整，未发现任何应计入而未计入的事项；全部查询留痕文件均已由查询人与复核人共同签字确认并归档。

### （五）从严认定与边界说明

为避免口径争议，我公司就以下边界情形作出从严认定说明：

1. 期间计算。凡行政处罚决定的作出时间或者其载明的违法行为发生时间任一落入自查期间的，均计入自查范围，不因二者时间差而排除；
2. 分公司与分支机构。分公司在自查期间内的行政处罚记录并入投标人记录一并核查与声明，不作分离处理；
3. 罚款金额。不设金额门槛，任何金额的罚款均纳入自查，从严于“较大数额罚款”的法定口径；
4. 处理状态。不以处罚已执行完毕、已整改、已过复议或者诉讼期限等理由对记录作排除或者淡化处理；如存在处于行政复议或者行政诉讼期间的处罚事项，将如实向采购人披露并接受认定；
5. 渠道差异。如不同官方渠道查询结果不一致，以处罚决定机关对应的官方渠道为准，并在2个工作日内向采购人书面说明差异情况。

1. 频次承诺：履约期间每季度按本章第二节（三）的口径与渠道开展合规复查1次，每年累计不少于4次，每次均形成由组长签认的书面复查记录；
