## 45.1 对否决项条款的总体响应

我方充分知悉，串通投标不仅直接触发投标被否决的后果，还将依据《中华人民共和国招标投标法》及其实施条例、《中华人民共和国政府采购法》及其实施条例等规定，面临中标无效、罚款、取消投标资格、列入不良行为记录名单乃至移送司法机关追究刑事责任等后果；同时，串通投标破坏公平竞争秩序，损害招标人与其他投标人的合法权益。基于此，我方对串通投标行为持零容忍立场，并将该立场贯穿于本项目的全部投标活动。

## 45.2 对 [REQ-0075] 的逐项响应：串通投标情形专项自查

依据 [REQ-0075] 的规定，评标委员会在评标过程中将重点核查串通投标情形，凡属于视为投标人相互串通投标情形之一的，其投标将被否决。我方理解，该条款所列情形包括但不限于：不同投标人的投标文件由同一单位或者个人编制；不同投标人委托同一单位或者同一人员办理投标事宜；不同投标人的投标保证金从同一单位或者个人的账户转出；不同投标人的投标文件异常一致或者投标报价呈规律性差异；不同投标人的投标文件相互混装；不同投标人的投标文件载明的项目管理成员为同一人。我方针对上述各项情形逐一开展对照自查，自查的组织方式、过程记录与结论如下。

自查组织方式：本次自查由我方分管法务的副总经理牵头，合规专员、投标工作组全体成员及外部执业律师共同参与；自查采取“制度核查＋记录核查＋人员访谈”三种方法，制度核查对照我方《投标行为合规管理办法》逐条验证，记录核查调取门禁记录、社保缴纳记录、银行流水与编制版本时间戳逐项验证，人员访谈覆盖全部参编人员与拟派项目管理成员，访谈记录经被访谈人签字确认。三轮自查分别完成于投标截止日前10日、前5日与前24小时，均形成书面自查报告并存档，可供评标委员会随时调阅。

本投标文件由我方投标工作组独立编制，编制地点为我方位于公司总部的投标专用办公区，该办公区在投标期间实行物理隔离与门禁管理，仅授权本项目投标工作组成员持卡进入。参与编制的人员均为我方在职员工，与我方签订劳动合同并由我方缴纳社会保险，编制期间未有任何其他潜在投标人的员工进入该区域，亦未向任何第三方提供投标文件的电子文档、纸质文本或其任何部分。我方投标文件的全部文字、方案、图纸、报价与格式排版均由我方独立完成，不存在与其他投标人的投标文件由同一单位或者个人编制的情形。上述事实可由我方办公区门禁记录、编制人员劳动合同与社会保险缴纳记录予以佐证，我方承诺应评标委员会要求在24小时内完整提供。

我方就本项目投标事宜出具的授权委托书，仅授权我方一名职工作为本项目投标的唯一授权代表，该授权代表与我方存在真实劳动关系，其身份证明、劳动关系证明及授权委托书原件已按招标文件要求随投标文件提交。我方未委托同一单位或者同一人员办理本项目任何投标事宜，亦未接受任何其他投标人委托代为办理投标事宜；招标文件的获取、澄清申请、投标保证金缴纳、投标文件递交与开标出席等全部投标事务，均由我方授权代表以我方名义独立完成。如评标委员会核查发现我方授权代表同时出现于其他投标人处办理本项目投标事宜，我方无条件接受投标被否决的处理结果，并依法承担相应责任。

我方的投标报价由我方商务与造价人员依据我方自身的企业定额、采购渠道、人力成本与管理费水平独立测算形成，测算底稿完整保存并可随时提交。编制期间，我方未与其他任何潜在投标人就报价策略、报价水平、下浮率或成本口径进行任何形式的沟通、协商或约定，未获取、未刺探亦未交换其他投标人的任何报价信息。为防止报价信息泄露，我方对商务标文件实行分段编制与分级授权查阅，完整报价在递交前24小时内方由商务负责人汇总封存，全过程接触人员不超过3人并逐一登记。据此，我方投标文件的内容与其他投标人的投标文件不存在异常一致的情形，我方的投标报价与其他投标人的报价不存在规律性差异，包括但不限于呈等差或等比排列、按固定比例下浮、呈相同梯度分布等情形。我方商务标组价过程文件与内部审核记录均标注编制人与复核人并留有完整的版本时间戳，可供评标委员会调阅核验。
