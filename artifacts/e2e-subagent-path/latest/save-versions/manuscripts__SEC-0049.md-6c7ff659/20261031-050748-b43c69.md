# 否决项（第10块）

## 一、响应总则

本章针对招标文件所列否决项条款进行专项响应与合规自查。我方在获取招标文件后，即由投标总负责人牵头，组织商务、技术、资料、法务四类岗位人员对否决项条款进行逐条研读与风险评估，形成《否决项风险清单》，并针对每一项风险制定了可执行、可核验的管控措施。本章就其中关于投标文件递交时限、递交地点与密封要求的条款[REQ-0032]作出正式响应，并同步披露我方为防止触发否决情形而建立的进度、人员、设备三重保障体系。

我方将否决项风险管理划分为识别、评估、控制、监测四个环节：识别环节，逐句拆解条款要件，不遗漏任何构成拒收情形的表述；评估环节，按发生可能性与后果严重度对风险排序，将"逾期送达"与"密封不合格"列为最高等级风险；控制环节，为每一项高等级风险配置前置节点、冗余资源与书面规程；监测环节，以节点签认、定时点名、定位回传等手段对执行状态进行连续监测，确保偏差在演变为否决后果之前被发现和纠正。

针对[REQ-0032]「3.6.1 投标人应当在投标截止时间前将投标文件递交至第一章规定的地点；逾期送达或者未按照招标文件规定密封的投标文件，招标人将拒收」，我方作完全响应、无保留响应。我方充分知悉：投标文件的送达时间以招标人或其授权签收人在第一章规定的递交地点实际签收的时间为准，而不以我方发出、寄出或启运的时间为准；投标文件的密封状况以递交现场查验时的状态为准。据此，我方承诺：

一是在投标截止时间前，将按招标文件规定编制、签署、密封完毕的投标文件，当面递交至第一章规定的递交地点，并当场取得签收凭证；

二是不采用快递、邮寄、委托无关第三方代投等任何可能造成送达时间不可控的方式递交投标文件；

三是严格执行招标文件关于正本、副本份数与分装密封的全部规定，确保密封形式完全合规；

四是如因我方原因导致投标文件逾期送达或密封不符合规定而被拒收，我方自愿承担由此产生的全部后果，不向招标人主张任何权利。

为使上述承诺具备可核验性，我方在本章第三节至第七节分别给出进度计划、人员配置、设备物料、密封规程与应急预案的量化承诺，全部节点均设置签认单据与影像留痕，可供招标人在需要时查验。

在版本控制方面，投标文件定稿后即行版本冻结，定稿文件的电子档与纸质档均加注版本号与冻结时间；冻结后的任何修改，均须经投标总负责人书面批准，并重新履行签字、盖章、装订、密封及三检流程，杜绝"旧版页面混入新版标书"的失误。

在时间基准方面，我方在T-5日对所有用于计时与记录的设备（车辆时钟、手持终端、拍照设备）进行统一校时，以国家授时中心发布的标准时间为唯一基准，避免因设备时钟偏差导致记录失真。在偏差处置方面，任一节点延误超过4小时的，由投标总负责人组织分析原因并重新排布后续节点；延误超过8小时或影响T-2日启运节点的，立即启用本章第七节应急预案，必要时增派人员与车辆。若招标文件规定的投标截止时间发生变更，我方将在知悉变更后24小时内按上述倒排逻辑重新发布进度计划，并保持同等的前置强度与冗余强度。

## 六、密封操作规程

针对[REQ-0032]中"未按照招标文件规定密封的投标文件，招标人将拒收"的规定，我方制定并执行如下密封操作规程：

1. 分装规则。严格按招标文件规定的正本、副本份数与分装方式执行；招标文件对分装有特别规定的（如报价部分单独密封、电子文件单独密封等），以招标文件规定为准。我方在T-7日前完成对密封规定的书面复核，如存在理解疑问，在招标文件规定时限内提出澄清，绝不凭推测操作。
2. 签署完备。密封前逐页检查签字、盖章的完备性，签署完备率未达100%的不得进入密封工序。
3. 密封动作。文件装入密封袋后，封口以封条覆盖，封条骑缝处加盖投标人单位公章；印文清晰、完整、可辨识，不使用印泥过浅、偏移或缺损的印章件。
4. 外袋标注。每一密封包外表面标注项目名称、标段（如有）、招标编号（如有）、投标人全称，并按内容分别注明"正本""副本"及内装文件名称；标注采用打印标签与手写双重方式，防止运输磨损导致标识缺失。
5. 三检制度。密封实行"自检—复检—终检"三检：资料与密封专员自检并签字，复核人复检并签字，投标总负责人在T-3日终检并签认；任一环节发现瑕疵，当场返工并对该密封包重新走完三检流程。
6. 影像存档。密封完成后，对每一密封包进行六面（上、下、前、后、左、右）拍照，照片含时间水印，与密封三检记录单一并归档，形成可追溯证据链。
7. 包装防护。密封包装入专用防压、防潮运输箱，箱内以缓冲材料固定，防止运输过程中封条磨损、水浸或压损。
8. 现场保持。递交前不拆封、不移位封条；确因意外发生封条破损的，立即向递交现场工作人员如实说明，并在投标截止时间前依规使用随身携带的备份密封文件完成递交，不以任何方式自行修补后隐瞒瑕疵。

## 七、逾期与密封瑕疵风险防控及应急预案

（一）三级预警机制。

- 黄色预警：T-1日18:00前未完成终检或未抵达目的地城市的，由投标总负责人直接介入，压缩非关键工序，增派1名人手支援，确保当日完成既定节点；
- 橙色预警：递交日前一日20:00前仍未抵达目的地城市的，立即启动备车与第二备选路线，递交组改为夜间赶路，确保递交日8:00前抵达目的地城市；
- 红色预警：投标截止时间前3小时仍未完成递交的，由投标总负责人统一指挥，向递交现场工作人员如实说明情况并请求予以优先核验，同时启动一切合法的加急措施，确保在截止时间前完成递交。

（二）交通与路线预案。出发前48小时完成路况、天气与交通管制信息查询，规划主路线1条、备选路线2条；主车与备车间隔15分钟错峰出发，分载主件与备份件；行驶途中每30分钟回传一次定位；任一车辆发生故障或事故，另一车辆立即按预案独立完成递交，不再等待事故车辆。

（三）极端天气与突发情况预案。出发前如预报递交日在途区域存在恶劣天气，递交组提前12小时以上出发；如在途遭遇道路封闭或管制，立即切换备选路线并同步向投标总负责人报告；如遇车辆故障，备车在30分钟内完成接驳；如遇人员突发疾病，由应急联络员协调替补人员，替换人员经投标总负责人确认职责后上岗。
