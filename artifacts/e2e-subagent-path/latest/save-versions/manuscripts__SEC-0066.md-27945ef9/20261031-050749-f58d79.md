## 二、对 [REQ-0050] 条款的理解

### （一）条款性质与法律后果

[REQ-0050] 位于招标文件否决项条款第（3）项，属资格性审查条款：凡触及该情形的投标，无须进入后续详细评审，即由评标委员会直接否决。其规范渊源为《中华人民共和国招标投标法实施条例》第四十条第（三）项，「不同投标人的投标文件载明的项目管理成员为同一人」的，视为投标人相互串通投标。本投标人理解，该情形属于法定的客观化认定标准：评标委员会只需查实「不同投标文件载明的项目管理成员为同一人」这一客观事实即可认定，无须另行证明投标人之间存在串通的意思联络或实际串通行为。

就法律后果而言，本投标人知悉：投标人相互串通投标的，投标无效；给他人造成损失的，依法承担赔偿责任；情节严重的，可被取消一定期限内参加依法必须进行招标的项目的投标资格，直至吊销营业执照；构成犯罪的，依照《中华人民共和国刑法》关于串通投标罪的规定追究刑事责任。本投标人对上述后果的严重性有清醒认识，将 [REQ-0050] 的自查确认列为本次投标编制工作的最高优先级事项。

### （二）条款的立法目的

招标采购实践中，个别投标主体围绕同一项目组建「一台班子、多块牌子」的投标联合：多个投标人表面上相互独立，实际由同一实际控制人操纵，共用同一批项目管理成员分别编制多份投标文件，以围拢报价、分食标段、排斥真实竞争。此类行为使公开招标的竞争机制形同虚设，直接侵害招标人利益与其他诚实守信投标人的合法权益。[REQ-0050] 以「项目管理成员同一」这一客观、外显、可快速核验的标准，将隐蔽的串通行为拦截在评审前端，是维护招标公平与采购质量的重要防线。本投标人完全认同该条款的立法目的，并愿以本章节的响应内容证明：本投标人是独立、诚实、具备完全履约能力地参与本项目竞争的投标人。

### （三）「项目管理成员」与「同一人」的认定口径

本投标人对认定口径的理解声明如下。其一，「项目管理成员」不限于项目经理一人，而是指投标文件（含商务部分、技术部分、资格证明材料及各类附表、承诺函）中载明的全部项目管理人员，包括项目经理（项目负责人）、项目技术负责人以及施工员、质量员、安全员、材料员、资料员、机械员等管理岗位人员和拟投入本项目的其他管理人员。其二，「同一人」以「姓名＋居民身份证号码」双重比对认定，不因所报岗位不同、职称不同、执业资格不同、报酬来源不同而影响认定结论。其三，本投标人已知悉，即便某人员仅在他人投标文件中「挂名」而未实际参与其项目管理，亦不影响「载明的项目管理成员为同一人」这一客观事实的成立。基于上述口径，本投标人已对全部11名项目管理成员逐一完成身份信息、社保信息、资格注册信息的三重核验，确认无一例外地专属服务于本投标人。

### （四）本投标人对条款的态度

本投标人无条件接受 [REQ-0050] 的约束，不寻求任何规避、变通或例外安排，主动配合评标委员会在评审阶段进行的任何核查。若经查实本投标文件所载项目管理成员与其他投标人存在身份重合，无论成因如何，本投标人均无条件接受按该否决项作否决投标处理，不提出异议与申辩，并依法承担相应责任。
