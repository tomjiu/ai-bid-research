### 3.1 禁止转包承诺

针对[REQ-0020]中"不接受未经招标人同意的任何形式的分包或转包"的规定，我方首先就转包作出承诺：中标后不将中标项目整体转包给任何第三方；不将中标项目肢解后以分包名义分别转包；不将合同权利义务概括转移给他人；不以内部承包、项目承包、挂靠经营等名义变相转包；不出租、出借资质供他人以我方名义施工。项目的施工组织、技术管理、质量控制、安全管理和资金结算，均由我方派驻的自有管理团队统一实施并承担责任。

履约中确因客观需要拟分包的，我方将先行向招标人提交书面申请，载明拟分包的内容、范围、金额及占比、拟选用分包方的资质与类似业绩、我方对分包方的管理办法与责任划分、质量与安全保证措施，经招标人书面同意后方可实施；未获同意的，相关工作一律由我方自有力量完成。即使发生经同意的分包，分包部分也不改变我方对招标人承担的全部合同义务，分包单位的行为视同我方行为，我方对分包范围的质量、安全、进度与农民工工资支付承担总责与连带责任。

结合本项目电子与智能化工程的内容特点与我方资质[EV-0128]的适用范围，我方承诺下列关键工作在未取得招标人书面同意之前一律不分包：智能化各子系统的深化设计与管线敷设、设备安装与接线、机房及配套工程、综合布线、系统集成与联调联试、软件部署与参数配置、系统试运行与检测配合、培训交付。上述内容属于我方资质适用范围内具备成熟自有能力完成的作业，配备有相应的持证人员与施工机具，无任何依赖外部主体实施的客观必要。
