## 二、对否决项条款 [REQ-0030] 的专项响应

本条响应按照"条款解析—响应结论—落实安排—风险控制"的顺序展开，所有结论与安排均可追溯、可核验。

### 2.1 条款原文与要求解析

[REQ-0030] 规定："投标人须在须知前附表规定金额（人民币 16 万元（大写：壹拾陆万元整））内提交投标保证金，未按要求提交的作否决投标处理。"

我方理解，投标保证金是投标人参与投标的信用背书与约束手段，其制度意义在于促使投标人严肃对待投标行为、约束撤标与串标等不当行为、保障招标人合法权益。该条款以"作否决投标处理"作为违反后果，属于招标文件中效力等级最高的强制性条款之一，不因投标人的技术优势或报价优势而获得任何豁免空间；同时，该条款明确了金额标准与违反后果，其具体执行还应遵循招标文件关于保证金形式、收款账户、提交时限、有效期的配套规定，我方均已一并研读并纳入响应范围。

对该条款进行结构化解析，可拆解出四项必须同时满足的核验维度：

（1）金额维度：提交金额须达到须知前附表规定的金额标准，即人民币160,000.00元（大写：壹拾陆万元整）；金额不足、大小写不一致、币种错误，均属于"未按要求提交"。

（2）时限维度：保证金须在须知前附表规定的时点之前完成提交；以转账形式提交的，以款项实际到达招标文件指定账户的时间为准，而非以我方发起转账的时间为准；以保函形式提交的，以保函签发并按招标文件要求送达的时间为准。

（3）形式维度：提交形式须为招标文件认可的形式，相应凭证须按招标文件要求随投标文件装订或单独密封提交，做到款、单、函三者相互对应、可以核验。

（4）后果维度：上述任一维度不满足，招标人及评标委员会将对我方投标作否决投标处理，我方无权以任何理由主张豁免、补正或宽限。

上述四个维度中，金额与时限是最容易在实务中出现差错的维度：金额差错多源于大小写不一致或转账金额录入错误，时限差错多源于对"到账时间"与"发起时间"的混淆。我方在本章节第二条所作的全部安排，均是针对这些高频风险点设置的针对性防线。
