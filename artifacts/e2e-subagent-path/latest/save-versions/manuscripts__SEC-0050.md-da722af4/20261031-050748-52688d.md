# 否决项（第11块）

## 一、否决项条款原文与响应总述

### 1.1 条款原文

招标文件否决项条款 [REQ-0034] 规定：「3.7.1 开标在第一章规定的投标截止时间及地点公开进行；投标人法定代表人或其授权代表须出席开标会议并携带有效身份证明文件。」

### 1.2 响应总述

我方已组织投标工作组对上述条款进行逐字研读与合规性评审，完全理解其构成要件、适用情形及法律后果。我方理解，开标是招标投标程序中的法定公开环节，招标文件通过 [REQ-0034] 将"按时出席开标会议并携带有效身份证明文件"设定为投标有效的强制性条件，其目的在于保障开标程序的公开性与可核验性，确认投标主体身份的真实性，防范冒名投标等情形的发生。我方完全认同并严格遵循这一制度安排。

该条款属程序性否决情形：投标人未按招标文件规定出席开标会议，或出席人员未携带有效身份证明文件的，其投标将被否决，不再进入后续符合性与技术评审环节。我方对此高度重视，已将该条款列为本次投标《否决项风险控制清单》的首要管控项，并围绕"人员、文件、行程、应急"四个维度建立了完整的保障体系：在人员维度，建立三级出席保障机制；在文件维度，实行清单化配备与三级核验；在行程维度，实行提前抵达与双线交通；在应急维度，预设六类异常情形的处置动作。四个维度相互衔接、互为备份，共同构成对 [REQ-0034] 的闭环响应，确保响应内容不流于书面承诺，而具有充分的可执行性与可核验性。

我方郑重声明：完全响应 [REQ-0034] 的全部要求，承诺由我方法定代表人或其正式书面授权的授权代表，在招标文件第一章规定的投标截止时间之前到达规定的开标地点，出席开标会议，并随身携带全部有效身份证明文件，随时接受开标现场的身份核验。若因我方原因出现任何不符合本条款的情形，我方无条件接受按否决项处理的全部后果，绝无异议。上述声明构成我方投标文件的正式组成部分。

### 1.3 响应编制依据与响应结论

本章节依据招标文件否决项条款 [REQ-0034] 的原文、招标文件第一章关于投标截止时间与开标地点的规定，以及我方投标工作组内部形成的《开标出席保障方案》编制。编制过程中，我方对照条款原文逐项自查：出席主体是否适格、授权手续是否完备、身份证明文件是否有效、到场时间是否充裕、异常情形是否有预案。自查结论为：我方具备完全满足 [REQ-0034] 全部要求的能力与条件，响应结论为"完全响应"。响应正文按照"条款原文—构成要件分解—组织安排与量化承诺—文件与核验—应急保障—佐证与承诺"的顺序展开，便于招标人逐项对照审查。

## 二、对 [REQ-0034] 的逐项分解响应

为杜绝理解偏差，我方将该否决条款拆解为"开标时间与地点、出席主体、身份证明文件"三个构成要件，逐项响应如下，并就"有效"的认定标准作出专门说明。

### 2.1 要件一：开标在第一章规定的投标截止时间及地点公开进行

我方已逐项核对招标文件第一章关于投标截止时间与开标地点的全部记载，并将相关信息同步至我方投标进度总控表，标注为强制性节点。开标时间与地点以招标文件第一章及其澄清或修改文件（如有）的最新版本为准，我方将持续跟踪招标人发布的澄清与修改信息，确保掌握的时间与地点信息始终为最新。我方承诺：

（1）严格按照招标文件第一章规定的时间与地点参加开标，不迟到、不缺席，不以任何理由要求变更开标时间或地点；

（2）在投标截止时间前完成投标文件的递交与签到，确保我方投标具备进入开标程序的基本条件；

（3）完全服从开标现场的程序安排，对开标过程记录予以当场确认；如对开标过程有异议，仅依法在规定的时限与渠道提出，不影响开标程序的正常进行；

（4）遵守开标会场纪律，服从现场工作人员引导，不进行任何干扰开标程序的活动。

若因我方自身原因未在投标截止时间前完成递交或未到场出席，我方自愿承担由此产生的一切后果，包括但不限于投标被否决、投标保证金不予退还等，绝不向招标人主张任何异议或索赔。

### 2.2 要件二：投标人法定代表人或其授权代表须出席开标会议

我方建立"法定代表人第一顺位、授权代表第二顺位、备选授权代表第三顺位"的三级出席保障机制：

（1）第一顺位：由我方法定代表人本人出席开标会议。法定代表人身份证明书随投标文件一并装订，同时随身携带原件备查，确保现场核验时人、证、文件三者一致；

（2）第二顺位：如法定代表人因不可抗力确无法出席，则由法定代表人签署授权委托书，委托授权代表出席。授权委托书载明委托事项、委托权限与委托期限，由法定代表人签字并加盖单位公章，附法定代表人及授权代表双方身份证明文件。其编制要点包括：委托事项明确限定于出席本次开标会议及相关事项；委托权限不涉及投标文件的实质性修改；委托期限覆盖开标全过程；被授权人信息与投标文件所附身份证明文件完全一致；

（3）第三顺位：我方同步办理一份备选授权代表的授权委托书，形成双保险。当第二顺位授权代表因突发情况无法到场时，备选授权代表立即顶替，确保出席安排不落空。

三级出席人员的姓名、职务及联系方式已在投标文件中如实填写，其签字样本与投标文件签署页保持完全一致，从源头杜绝"投标文件签署人与开标出席人不一致"的合规风险。三级名单在开标日前15个工作日冻结，冻结后原则上不再变更；确需变更的，须经我方投标工作组负责人书面批准，并同步更新全部身份证明文件。

### 2.3 要件三：携带有效身份证明文件

我方制定了《开标会议身份证明文件清单》，对法定代表人出席与授权代表出席两种情形分别明确应携带的文件种类、份数与效力要求（详见本章节第四部分），并在"出发前、抵达开标城市后、进入开标会场前"三个时点执行逐项核验。文件配备严格执行"清单管理、双人复核、原件随身"原则，任何一份文件未按清单到位，即视为核验不通过，不得出发。我方承诺：所携带的全部身份证明文件均真实、有效、在有效期内，与投标文件所附相应文件完全一致，可随时供招标人、开标监督人员及公证人员（如有）当场核验；如现场核验发现任何不一致，我方无条件配合澄清，并服从招标人的认定结果。

### 2.4 对"有效"的理解与执行标准

我方将条款中的"有效身份证明文件"理解为：文件形式合法、内容真实、在有效期内、与投标文件所载信息一致、且能与出席人员本人当场核对无误。据此，我方在执行中把握三条标准：一是"人在证在"，出席人员与所携证件一一对应，不代携、不转借；二是"证证一致"，现场出示的原件与投标文件所附复印件及登记信息完全一致；三是"证时相符"，全部证件的有效期均覆盖开标日当日，凡临近有效期的证件一律提前换新，不留任何争议空间。

## 三、出席开标会议的组织安排与量化承诺

### 3.1 出席人员配置

我方按"1+1+1"模式配置出席团队：法定代表人（或授权代表）1人，为出席责任人，对满足 [REQ-0034] 的出席要求负全责；投标负责人1人，随行协助处理签到、文件出示、开标记录确认等事务；机动保障人员1人，负责交通、通讯与应急联络。授权代表出席情形下，团队人数不少于3人。出席责任人确定后，即行办理其行程审批与公务衔接，确保开标日期间无并行安排；全部出席人员在开标日前不安排其他公务行程，通讯保持24小时畅通。

为便于招标人核验，我方对出席开标会议作出如下可核验的量化承诺，各项承诺均对应明确的完成时点或数量标准，可由内部记录及现场表现直接核验：

| 序号 | 承诺事项 | 量化承诺 |
| --- | --- | --- |
| 1 | 出席人数 | 不少于2人；授权代表出席时不少于3人 |
| 2 | 到场时间 | 不迟于开标时间（投标截止时间）前60分钟到达开标地点 |
| 3 | 授权委托书办理 | 开标日前10个工作日完成签署与用印 |
| 4 | 文件一致性核对 | 开标日前5个工作日完成身份证明文件与投标文件的一致性核对 |
| 5 | 身份证明文件核验 | 出发前24小时完成第一次全项核验；出发当日出发前2小时完成第二次全项核验 |

| 7 | 现场配合 | 无条件配合身份核验与开标程序，核验环节用时不超过招标人要求 |
| 8 | 通讯畅通 | 出席责任人手机自开标日前48小时起保持24小时开机，并预留2个备用联络号码 |

### 3.3 进度控制节点

我方将出席保障工作纳入投标进度总控表，设置以下控制节点：开标日前15个工作日，确定出席人员三级名单并冻结；开标日前10个工作日，完成授权委托书及法定代表人身份证明书的编制、签署与用印；开标日前5个工作日，完成全部身份证明文件与投标文件的一致性核对；开标日前3个工作日，完成交通与住宿预订；开标日前1日，抵达开标城市并完成开标地点实地踏勘与路线确认；开标日，按第3.2条承诺的时间到场签到。每一节点均由投标负责人签字确认，各节点完成情况形成《进度确认单》，作为内部考核与责任追溯的依据；任一节点逾期即触发升级处理，由我方分管领导直接督办，确保不影响开标出席。

### 3.4 人员责任分工

### 3.5 出席人员培训与交底

开标日前5个工作日，投标负责人对全部出席人员进行一次专项交底，内容包括：开标时间与地点、现场流程、应携带文件清单、身份核验应对口径、突发情况处置动作及联络方式。交底形成书面记录并经出席人员签字确认，确保每一名出席人员均清楚自身职责与处置要点，避免因个人疏忽导致程序性失误。

## 四、身份证明文件清单与三级核验机制

### 4.1 文件清单

法定代表人出席情形下，出席人员随身携带：①法定代表人身份证明书（原件，载明姓名、职务、身份证号，加盖单位公章）；②法定代表人本人有效居民身份证（原件）；③上述身份证的复印件（加盖单位公章，与投标文件所附一致）。

授权代表出席情形下，随身携带：①授权委托书（原件，法定代表人签字并加盖单位公章，载明委托事项、权限与期限）；②授权代表本人有效居民身份证（原件及加盖公章的复印件）；③法定代表人身份证明书（复印件，加盖单位公章）；④法定代表人有效居民身份证（复印件，加盖单位公章）。

两种情形下均随带企业营业执照副本（原件或加盖公章的复印件）备查。全部文件按清单装袋编号，袋面标注文件名称与份数，并另备一套复印件作为应急备用件，随行分开存放。

### 4.2 效力要求

全部身份证明文件须同时满足：在有效期内；所载信息与投标文件所附文件完全一致；签字、盖章齐全清晰；复印件均加盖单位公章。任一要素不满足，即视为不合格文件，立即启用备用件并同步补制；对"有效"存疑的文件，一律按不合格处理，不带疑问进入会场。

### 4.3 三级核验机制

一级核验（出发前24小时）：按第4.1条清单逐项核对，形成核验记录并由核验人与复核人双人签字；二级核验（出发当日出发前2小时）：再次逐项确认文件在身、证件在有效期内、签字盖章清晰；三级核验（进入开标会场前）：出席责任人现场复核并签字确认。三级核验记录随投标工作组内部资料存档备查，确保任一时点发现问题均有充足补救时间。

### 4.4 文件制作与保管规范

身份证明文件统一由投标负责人制作、法务人员复核，用印执行我方用印审批流程并留存记录；制作完成后的原件由出席责任人随身保管，复印件与备用件由机动保障人员分别保管，实现"原件随身、备用分管"，最大限度降低遗失、损毁风险。

## 五、到场保障与应急预案

### 5.1 到场保障措施

我方按"提前抵达、就近入住、双线交通"原则组织到场保障：开标日前1日抵达开标城市，住宿地点距开标地点车程不超过30分钟；开标日按"轨道交通＋预约出租"双方案准备交通，并预留不少于60分钟的机动时间；开标地点、签到入口与最佳路线已于开标日前1日实地确认，留存书面路线图备查。如开标地点位于交通管制区域，将提前办理车辆通行手续或改用公共交通。

### 5.2 应急预案

针对可能影响按时到场及身份核验的异常情形，我方制定以下应急预案：

（1）出行延误：如遇交通管制、航班延误等，立即启用备用交通方案；预计到场时间晚于开标时间前30分钟时，由机动保障人员先行赶往会场向招标人说明情况，出席责任人改换最快交通方式赶赴现场；

（2）出席人员突发疾病或意外：第一顺位人员异常时，第二顺位授权代表立即启用；第二顺位异常时，启用第三顺位备选授权代表；如确因极端不可抗力导致三级人员均无法到场，我方将在投标截止时间前以书面形式向招标人报告实际情况并请求指引，绝不隐瞒、不拖延；上述启用顺序在任何情形下均以"确保至少一名适格人员按时到场"为唯一目标；

（3）身份证明文件遗失或损毁：立即启用随身备用复印件，同时联系属地公安机关加急办理临时身份证明；授权委托书遗失时，由法定代表人立即重新签署并加盖公章，通过可保障时效的方式送达现场；

（4）通讯中断：出席责任人预留2个备用联络号码，待命联络员自开标日前48小时起随时待命，负责信息转接与外部联络；

（5）极端天气或自然灾害：密切关注开标日前72小时内的气象与灾害预警，出现可能影响出行的预警时，提前改签更早班次或改乘地面交通，确保按承诺时间到场；

（6）证件临期失效：出发前核验中发现任一证件有效期不覆盖开标日的，立即启动补办并在开标日前完成更换；确实无法完成的，按本条第（2）项机制启用下一顺位出席人员。

### 5.3 应急组织与演练

应急预案由投标负责人担任现场处置责任人，分管领导担任决策人。开标日前3个工作日，由投标负责人组织一次桌面推演，覆盖上述六类场景的触发条件、处置动作与责任岗位，重点检验信息传递的及时性、处置动作的正确性、备用资源的可得性；推演记录存档备查，接受招标人核验。
