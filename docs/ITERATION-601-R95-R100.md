## 语义边界如实记录（重要）

1. **短窗 ≠ 违规**：公开招标法定最短 20 日的起算点是
   「招标文件开始发出之日」（招标投标法第二十四条），公告
   发布日通常晚于或等于该日——十八节以发布日近似是**偏短
   估计**；竞争性磋商/询价等方式法定期限更短。短窗清单是
   供人工复核的研究提示，不是合规认定。
2. **品类归并不臆造**：category 是 LLM 抽取面自由文本，本批
   只做清洗后精确匹配——「信息化」与「信息技术」的映射关系
   由研究者判断，研究面不做词表折叠（区别于区域的省份封闭
   枚举归一——那是地理事实，这是语义判断）。
3. **跨平台信号是实证非猜测**：只有簇成员中 ≥ 2 个**可解析**
   平台域名才计跨平台；全簇缺 URL = 无法判定 = 不算（宁可
   少报不虚报）。域名无点形态（内网名/纯中文）计缺同理。
4. **倒挂不进分布**：截止早于发布的记录是数据问题（十七节
   语义审计揭示），进十八节分布会污染统计（-31 日会拉爆
   min）——两节职责分离，各计各的账。
