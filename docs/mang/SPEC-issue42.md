
```

```

## 八、版本历史（A+B+skill）

### 自动保存（软件职责）

```
每 30 秒检查一次：
  如果文件内容有变化 → 存一份快照
  位置：<工作区>/.mang/history/<文件名>/<时间戳>.md
  同时在 .mang/history/index.json 记元数据
```

### AI 主动存（MCP + skill）

```
1. 新增 MCP 工具 `save_version`（bid-mcp 里加）
2. 参数：file_path, message（版本说明）
3. 在 skill 工程规范里写明：
   「每完成一个章节，调用 save_version 存版本」
```

### 历史面板

```
Changes 侧栏显示：
  2026-10-29 14:30  AI 存版本  第2章 技术方案完成
  2026-10-29 14:00  自动快照   (无变化跳过)
  2026-10-29 13:30  AI 存版本  第1章 概述完成

点击任一条 → 预览该版本
[回滚到此版本] 按钮
```

### diff 对比

```
⚠️ 关键：只在 md 层做 diff
  - 因为源头是 md（AI 生成）
  - docx/pdf 是最终产物，不做 diff
  - md 可以逐行对比（类似 git diff）
```
