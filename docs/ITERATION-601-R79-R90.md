## 逐轮明细

### 批 L：数据质量与可观测

- **R79** 近重复公告检测核心 `src/analyze/duplicates.py`——项目名
  保守归一（NFKC + 全半角 + 删标点，保留全部文字：一期≠二期 是
  特征不是缺陷）；**pigeonhole 块倒排**生成候选（分块数按
  `(tol+1)/(1-r)+1` 通用式放大，数学保证不漏检）；**字符集对称差
  下界**快筛（`levenshtein ≥ max(|sa−sb|,|sb−sa|)`——可证明的
  否决条件，替代 Jaccard 启发式）；**Ukkonen 带限 DP** 精算
  （band 内 O(len·(2tol+1)) + 行早停）；并查集传递闭包聚类。
- **R80** 近重复接入 analyze——报告**第十六节**（无簇也明示
  「查过了且干净」，不留白猜测）+ payload `duplicates` 键 +
  TOC 可导航 + 节序编号。
- **R81** 语义质量审计 `semantic_health`——四类「填了但可疑」：
  预算语义（负/零/超大>50 亿疑单位错位/非数值）、日期逻辑
  （发布晚于截止/未来/远古<2015 电子化分水岭）、标识完整
  （bid_id/名称缺失）、标识唯一（ID 重复——防 `--import` 拼接
  源与外部直写库）；加权健康分（标识 > 日期 > 预算）。
- **R82** `data-quality` 独立命令——秒级质量巡检（不跑全分析面），
  `--json` CI 门槛面；**审计揭示不拦截**（发现问题仍退 0——
  门槛拦截是 R87 的显式 opt-in）；报告十七节同源单点渲染。
- **R83** 运行台账可观测——`StageResult.duration_seconds` 四阶段
  monotonic 计时 + `db --runs [N]` 台账渲染（状态/参数/阶段链@
  耗时；failed 如实显示「未收口」；旧库 stages 无耗时字段兼容）。
- **R84** 契约防漂移——analyze payload **键集精确断言**（加键
  必须过目 EXPECTED_KEYS 并同步 USER-GUIDE，防静默破坏
  `--diff`/`--json` 下游）+ 文档契约测试扩展。
- **R85** 批 L 冒烟——fixture 真链路联动（五条同名「智慧水务
  运维服务」聚簇 + 十六/十七节真渲染 + `db --runs` 耗时链）。
- **R86** 双平台冒烟步序纳入新面 + 修 ps1 双 BOM 回归单 BOM。

### 批 M：质量门槛与真实语料实拍

- **R87** `data-quality --min-score N` 质量门槛——低于阈值退 2
  （**复用数据错误域**，不新增退出码——保「只增不改」承诺）；
  JSON 面含 `gate_passed`（CI 可从 stdout 或退出码双判）。
- **R88** `db --export --dedupe` 近重复感知去重快照——簇内保留
  导出序首条、**库不动**（快照是研究视图）、纯数组兼容
  `--diff` 消费方、CSV/JSON 同语义、剔除分账 stderr。
- **R89** 预算单位错位**群体对照**——中位数相对证据（万倍比
  双向检测：元↔万元错位恰好 10⁴ 倍）；小样本（<5 有效预算）
  如实 skip 不硬猜；零/负不参与基准（防拉偏对照）。
- **R90** 真实语料实拍——`real-corpus/gov-procurement` 576 条
  真实公告标题：**26 簇 / 78 条 / 13.5% 检出率 / 0.03 秒 /
  预算不耗尽**；真实改包族落地（中科院亚热带所包 6-9 同族、
  人大常委会新闻稿三平台转发、北大人民医院分批采购）——
  检出即真信号，非合成数据自证。

## 语义边界如实记录（重要）

1. **一期/二期聚族是特性**：与「加（二次）」同为 1-2 步编辑——
   按定义就是近重复；采购研究中它们本是同项目不同阶段，聚族
   正是研究者需要的信号（提示人工复核，非事实认定）。
2. **审计揭示不拦截**：`data-quality` 无门槛时发现问题退 0——
   揭示是职责；拦截（`--min-score`）必须显式 opt-in。
3. **预算耗尽诚实截断**：批量采购同模板名超 5 万候选对时跳桶
   并在报告/导出/stderr 三面明示「对比不完整」，不装完成。
